Deliberate standalone differences (do not blindly port):

- One-cell brush and no thickness settings are extraction scope, not a full-mod fix. Full Shapes must retain variable thickness.
- Standalone uses rounded centerline interpolation followed by deduplication. Original diagonal lines 183,191,201 subtract floating thickness/2 before rounding, while axial lines use integer floor(thickness/2). This inconsistency changes half-step ties, especially odd widths, but the simple positive 45-degree width-1 case (10,10)->(14,14) reproduced correctly. Do not label every diagonal shifted. Define and test a consistent odd/even brush anchoring policy, shallow/steep slopes, both signs and reversed direction before changing its rasterization.
- Standalone clamps off-map samples before interpolation and stores only in-bounds cells. That protects memory but introduces edge-tracing semantics; full-mod owner should choose whether to clamp, clip segments, or ignore outside samples and document/test it.
- Standalone patches UpdateCellBuffer only for its own worker to avoid vanilla cached buffer reuse after resets, independently of game tick. Full Shapes already replaces UpdateDragCellsIfNeeded while controls are active, with frameCount rather than game tick; integrate state invalidation into that pipeline instead of copying a competing prefix. Audit its fallback vanilla-worker mode separately while paused.
- Unique defs, one-cell palette label, Harmony dependency and full-mod incompatibility are standalone packaging choices, not parity changes.

Regression handoff: first-call origin!=target; same-origin new stroke; release and vanilla cancel; full-mod shortcut and menu shape changes; selected designator changes; map switch; new/load game; paused stationary width changes; widths 1,2,3,9 and shrinking; asymmetric map coordinates; looped moving input; diagonal all octants and reversal; off-map input; no stale path joining. The standalone's 18 checks pass; full-mod width-specific cases require new tests.

Evidence harness: original source was copied read-only into ignored local Tools/OriginalRegression with minimal IntVec2/IntVec3 and Thickness host doubles, then run under .NET 10. Observed outputs: first moved endpoint=(10,0,10) only; thickness 1->9=9 cells in 9..11; moving-loop path=10001 entries; same-origin without reset=6 cells. These are deterministic geometry/state observations, not in-game smoke results.
